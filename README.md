# 🛡️ AEGISNET v5.1
### **Systemic Risk Digital Twin & Predictive Financial Intelligence**

AEGISNET is a sophisticated AI-powered platform designed to monitor systemic financial risk, forecast potential crises, and simulate contagion scenarios across interconnected institutions. 

Built for regulators, policymakers, and financial researchers, it bridges the gap between raw data and proactive stability insights.

---

### 🚀 Key Features
* **Systemic Risk Dashboard:** Real-time monitoring of institutional stability with circular risk gauges and live leaderboards.
* **Crisis Prediction Engine:** Predictive ML models that forecast severity before it peaks, featuring **SHAP-based explainability** (Tornado Charts) for transparent decision-making.
* **Policy Intervention Sandbox:** A regulatory playground to test interventions (liquidity injections, capital buffers) and visualize immediate systemic impact.
* **Contagion Simulator:** Advanced mapping of default cascades to understand how individual failures propagate through a network.

### 📂 Project Architecture
- `analysis_engine.py`: The Python core handling risk modeling and data processing.
- `backend/routers/`: Scalable API architecture for financial data delivery.
- `components/`: Modular UI units focused on data visualization and minimalist design.
- `services/`: Logic layers for API integration and AI orchestration.
